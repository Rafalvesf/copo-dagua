# Onboarding — Validações

| Campo | Regra | Mensagem de erro (PT) |
|---|---|---|
| Nome do(s) noivo(s) | Obrigatório pelo menos 1 nome | "Precisamos de pelo menos um nome" |
| Data do casamento | Data futura, ou "ainda não sei" | "Escolhe uma data futura" |
| Localização | Obrigatória, resultado válido do autocomplete | "Seleciona uma localização da lista" |
| Nº estimado de convidados | Número inteiro positivo, opcional | "Introduz um número válido" |
| Orçamento estimado | Número positivo, opcional | "Introduz um valor válido" |
| Nome do negócio (parceiro) | Obrigatório, mínimo 2 caracteres | "Introduz o nome do teu negócio" |
| Categorias (parceiro) | Mínimo 1 selecionada | "Escolhe pelo menos uma categoria" |
| NIF | 9 dígitos, checksum português válido | "NIF inválido" |
| Fotos de portefólio | Mínimo 1, máximo 3, JPG/PNG, ≤ 10MB cada | "Adiciona pelo menos uma foto" |
